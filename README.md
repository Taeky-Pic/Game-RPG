# HBC 오피스 어드벤처 (데모)

사내망에서 동료들과 같이 하는 **쿼터뷰 픽셀아트 실시간 액션 RPG** 데모입니다.
클릭으로 이동하고, 부서(직업)별 스킬로 사내 몬스터를 소탕합니다.

![컨셉](docs/concept.png)

## 실행 방법 (서버 PC 1대만 설정하면 됩니다)

1. 서버 역할을 할 PC 1대에 **Node.js 18 이상**을 설치합니다 (https://nodejs.org, LTS 버전).
2. 이 폴더에서 `start.bat`을 더블클릭합니다. (Mac/Linux는 `./start.sh`)
   - `npm install` 같은 추가 설치는 **필요 없습니다** (외부 라이브러리 0개).
3. 창에 나오는 주소로 접속합니다.
   - 서버 PC: `http://localhost:3000`
   - 동료 PC: `http://<서버PC의 IP>:3000` (창에 IP가 표시됩니다)
4. 동료가 접속하지 못하면 서버 PC의 **Windows 방화벽**에서 Node.js 허용(사설 네트워크)을 확인하세요.
   포트를 바꾸려면 `set PORT=8080` 후 실행합니다.

동료 PC는 **Chrome 또는 Edge 브라우저만 있으면** 됩니다.

## 조작법

| 입력 | 동작 |
|---|---|
| 좌클릭 (땅) | 이동. 누르고 있으면 커서를 계속 따라감 |
| 좌클릭 (몬스터) | 자동으로 다가가서 공격 |
| 우클릭 / `1` | 부서 스킬 (마우스 위치/방향) |
| `F` | 믹스커피 (HP 40%, MP 20% 회복) |
| `5`~`8` | 감정 표현 (❗ ❤️ 💢 💧) |
| `Enter` | 채팅 |
| `H` | 도움말 |
| NPC 클릭 | 공무팀 박선임과 대화 |

## 부서(직업)

| 부서 | 역할 | 스킬 |
|---|---|---|
| 공무팀 | 근접 돌격 | ⚡ 결재 돌진: 커서 방향으로 돌진하며 경로의 적 220% 피해 |
| 유지보수팀 | 근접 탱커 | 🔧 스패너 회오리: 주변 적 180% 피해 + 밀쳐내기 |
| 인사팀 | 원거리 서포터 | 💗 칭찬 하트 폭격: 범위 150% 피해 + 기절, 아군 회복 |
| 재무팀 | 원거리 마법 | 📄 서류 폭풍: 넓은 범위 200% 피해 |
| EHS팀 | 힐러 | ✚ 안전 제일 오라: 주변 동료 30% 회복 + 방어력 증가 |

## 데모 내용

- **HBC 본사 앞** (안전지대, 회복 3배) + **동쪽 사냥터**
- 몬스터: 야근 슬라임(Lv1) → 버그 벌레(Lv3) → 결재 지연 유령(Lv5, 원거리) → **마감 골렘**(보스, 범위 내려찍기 예고)
- 경험치/레벨업, 퀘스트 "사내 버그 소탕 작전", 사망 후 5초 뒤 부활
- 몬스터를 같이 때린 사람 모두 경험치를 전부 받음 (협동 친화)
- 채팅 말풍선, 감정 표현, 미니맵

## 구조

```
server/server.js   HTTP 정적 파일 + WebSocket 서버, 20Hz 게임 루프
server/ws.js       외부 라이브러리 없는 WebSocket 구현
server/game.js     서버 권한형 게임 로직 (이동/전투/몬스터 AI/스킬/퀘스트)
shared/data.js     서버·클라이언트 공용: 맵 생성, 직업/스킬/몬스터 수치, A* 길찾기
client/            브라우저 클라이언트 (Canvas 2D, 픽셀아트는 코드로 생성)
client/assets/     컨셉 이미지에서 잘라낸 직업 카드, 대화 초상화
```

수치(체력, 공격력, 쿨타임 등)는 `shared/data.js` 한 곳에서 바꾸면 됩니다.
